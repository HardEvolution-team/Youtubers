# Youtubers+ Mod Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Youtubers+ Mod** 1.8.0 (1.7.10) by supercat765.

- Original: https://www.curseforge.com/minecraft/mc-mods/youtubers-mod
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.38.0+

This port contains **no original assets**. Put your own copy of the original jar (`youtubers-1.8.0-MC1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures, sounds and names from it at runtime.

Player-skin downloads of the original used skins.minecraft.net, which no longer exists; the port resolves skins through the Mojang profile service and the game's own skin manager.
